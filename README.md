## Preview locally

No build system or package installation is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/M-Abdullah-Shahzad/Portfolio.git
   cd Portfolio
   ```

2. Open `index.html` in a browser.

The profile image is loaded from the adjacent `ab.jpg` file, so keep both files in the repository root.

## Publish with GitHub Pages

After merging the approved portfolio update:

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and the `/(root)` folder, then save.
5. Use the URL GitHub Pages displays in the Pages settings.

The website is static and does not require a server-side runtime.
